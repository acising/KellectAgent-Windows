# config/filter.txt - runtime filter configuration (read by initFilter() at startup)
#
# Format: a section name on its own line, then one entry per line.
# Lines starting with '#' are comments. Unknown sections are ignored, so a
# filter.txt from an older release keeps working (see the note at the bottom).
#
# filteredProcessID:  PIDs whose events are dropped (blacklist).
#                     One PID per line, or several on one line ("0 4 128").
#                     Built-in {0, 4, 128, self, kellect.exe/KellectConsole.exe}
#                     always apply; entries here are additive.
# droppedEventName:   event names (from eventStruct_*.xml) dropped at firstFilter,
#                     before parsing. Same effect as CLI -x; -x entries are
#                     additive. Use it for high-volume low-value noise.
# filteredImageFile:  image paths whose Image-Load events (and their callstacks)
#                     are dropped.
